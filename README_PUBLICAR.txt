CRIARDESIGN - SITE SEO + MODELAGEM 3D

Arquivos principais:
- index.html: página principal do site
- assets/: imagens otimizadas do site
- robots.txt e sitemap.xml: arquivos básicos para SEO
- _headers e .htaccess: ajudam com políticas de segurança e referrer para embeds

Para publicar:
1. Envie todos os arquivos da pasta para a hospedagem.
2. Mantenha a pasta assets junto do index.html.
3. No sitemap.xml, troque https://seudominio.com.br/ pelo domínio real.
4. Depois de publicar, cadastre o domínio no Google Search Console e envie o sitemap.

Observação sobre vídeos:
Os vídeos estão configurados para rodar dentro da página via player incorporado do YouTube. Para funcionar corretamente, publique em hospedagem HTTPS. Abrir como arquivo local no computador pode gerar erro do player por falta de origem válida.
